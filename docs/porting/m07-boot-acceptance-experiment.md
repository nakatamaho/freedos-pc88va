# M07 PC-88VA firmware boot-acceptance experiment

M07 separates a reproducible public probe harness from a local private VAEG
observation gate. The public harness does not establish firmware behavior. It
constructs controlled inputs with no private dependency and verifies that the
only differences from the accepted M06 media are declared boot-record bytes.

## Scope and prior contracts

The experiment consumes the M05 media layout and the M06 derived image without
changing either accepted golden. The 4,414-byte M06 `KERNEL.SYS` remains an
inert compile-only carrier. The M07 probe neither reads it nor claims that it
is a functioning FreeDOS kernel.

The components and gitlinks are unchanged. Public CI is ROM-free and does not
run VAEG. Exact firmware identity, generated execution images, traces,
registers, addresses, sector-read observations, the accepted variant, and the
promotion proposal remain in local private evidence.

## Probe layout

The project-authored probe is assembled as a flat 16-bit binary by the NASM
binary already identified by the accepted M06 toolchain evidence. It is nine
bytes long and is placed at byte offset 62 of the 1,024-byte reserved sector.
The first seven bytes form an externally recognizable sequence of register
no-ops; the final two bytes are a self-loop. Before the marker it uses no
stack, call, return, interrupt, I/O, DMA, timer, video, keyboard, or disk
operation.

Bytes 3 through 61 retain the accepted M06 BPB and extended BPB. The three-byte
entry field branches to byte 62. The remaining probe area is filled by a
documented deterministic offset-based pattern so a private observer can test
which bytes are present without publishing firmware-derived values.

## Controlled variants

The canonical matrix is in `config/m07/variants.json`:

| ID | Boot payload | Marker at byte 510 | Marker at byte 1022 |
| --- | --- | --- | --- |
| V00 | Accepted M06 placeholder | absent | absent |
| V01 | M07 probe | absent | absent |
| V02 | M07 probe | `55 AA` | absent |
| V03 | M07 probe | absent | `55 AA` |
| V04 | M07 probe | `55 AA` | `55 AA` |

These marker bytes are experimental variables, not PC-88VA facts. No public
file identifies an accepted variant. Every variant retains the M06 geometry,
FAT copies, root directory, payloads, timestamps, and D88 structure. Each D88
extracts to its corresponding raw image byte-for-byte.

## Public reproducibility gate

`make m07-public` builds the probe and all five variants in two independent
result trees, compares every generated byte, runs the focused negative tests,
and verifies the textual public golden. Generated `.bin`, `.img`, and `.d88`
files remain ignored and untracked.

The pinned public VAEG source revision is
`2a6c3944bab1fb691261fa2f0950dc4a2faeab8c`. Its standard macOS binary was
built from two clean checkouts and was byte-identical. It provides fixed model
selection, FDC trace, no-config, and no-backup-memory controls, but its CPU
trace implementation is not compiled into the standard production binary.
VAEG is a read-only external dependency and is not copied into this repository.

The available trace-enabled configuration is insufficient for M07. Enabling
the trace alone fails to compile at this revision. Enabling the test suite as a
workaround also activates a flat test-memory seam, so that executable cannot
serve as production-firmware evidence. A later public VAEG main revision was
audited at `7f9337611d3419516c6d5f1f5f8c389eb3570693` and retained the
trace-only compile failure. M07 therefore does not patch VAEG or accept a
test-memory observation.

## Private observation and promotion boundary

Private trials use a fresh PC-88VA process and immutable input copy for each
variant. Canonical private projections retain instruction order, disk reads,
architectural state, addresses, and result classification while excluding only
nonsemantic host fields defined before comparison. At least two matching
trials are required for a deterministic observation.

The tracked public result contains only whether the gate ran, whether it was
conclusive, input-preservation status, trial and field counts, and resolved or
unresolved field names. It never contains a resolved value. The mandatory
promotion state is `prohibited_pending_user_approval`; M08 cannot consume a
private-derived value until the owner separately approves a minimal public
fact or an independently public source establishes it.

M07 VAEG evidence is emulator evidence, not real-hardware verification.

## Current result

The public probe and all variants are reproducible, but the private observation
gate is inconclusive. Ten bounded clean trials preserved every input, yet no
controlled probe execution could be established with an approved production
trace binary. All eight entry-contract fields remain unresolved and the public
promotion status remains `prohibited_pending_user_approval`.

The minimum safe recovery is a separately reviewed VAEG change that makes the
existing bounded CPU trace build in a production-memory configuration. After
that change is published, M07 must rerun every variant twice from clean state.
M08 remains blocked.
