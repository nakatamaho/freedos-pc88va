# M00: Repository Scaffold

Status: scaffold.

M00 establishes the parent repository layout, the two editable experimental
fork branches, the read-only COUNTRY.SYS data submodule, exact gitlink and lock
metadata, public contribution rules, and host scaffold verification.

M00 does not modify component source, choose packages, install a toolchain,
build, generate images, run VAEG, or test real hardware. `HOST PASS` applies
only to the completed host scaffold checks. VAEG and hardware evidence are
`NOT RUN`.
