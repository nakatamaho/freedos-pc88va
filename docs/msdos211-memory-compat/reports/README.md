# Milestone reports

Create exactly one report per `/goal` invocation:

```text
M0-remove-bios-shims-and-rebaseline.md
M1-native-capacity-decoder.md
M2-native-capacity-to-dos-arena.md
M3-low-memory-byte-accounting.md
M4-<one-proven-reclaim>.md
M5-final-memory-verification.md
```

Do not pre-create a success report. A BLOCKED report is a valid milestone
result and must preserve the exact failure evidence.
